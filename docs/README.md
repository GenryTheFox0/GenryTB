# Вики GenryTB

**GenryTB** — бесплатный конструктор модов с открытым кодом для «Зайчика» (Tiny Bunny). Историю пишешь
по-русски карточками или обычным текстом. Программа сразу показывает кадр так, как его нарисует игра, сама собирает
мод и кладёт его в игру: в главном меню «Зайчика» появляется кнопка «Моды».

### Коротко об истории

Сначала был конструктор для «Бесконечного лета», [GenryBL](https://github.com/GenryTheFox0/GenryBL). 2 октября 2026
Генри решил сделать такой же для «Зайчика», «только без багов». Ядро написали с нуля: своё чтение архива игры, своё
превью, свой компилятор в Ren'Py. Потом пошли механики самой игры: выбор подсветкой, выбор на время, «Пропал
ребёнок», полароид, телефон, камень-ножницы-бумага. Финалом стал мод-пример «Спасти Катю»: в игре Катя гибнет при
любом раскладе, а здесь её можно спасти.

## Как делать мод

- **[Шпаргалка команд](commands.md)**: все команды на одной странице, с примерами.
- **[Выборы, очки и концовки](choices.md)**: выбор, подсветка на картинке, выбор на время, счётчики, условия,
  достижения, эпилог и титры.
- **[Мини-игры](minigames.md)**: камень-ножницы-бумага (23 набора рук, 7 мест, три времени суток), пазл, телефон,
  загадка, осмотр, борьба, полароид, предмет в руке.
- **[Камера, движения и эффекты](camera-effects.md)**: наезд, шаги, сердце, камера за мышью, персонаж вздрагивает и
  смеётся, снег, VHS, телевизор, воспоминание, глазок.
- **[Моды внутри оригинала](hooks.md)**: своя сцена в любом эпизоде игры, свой поворот сюжета. Разбор «Спасти Катю».
