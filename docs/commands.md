# Шпаргалка команд

[← Вики](README.md)

Мод — это файл `story.txt`. Одна строка — одна команда или реплика. Карточки в редакторе пишут ровно эти строки,
поэтому всё, что ниже, можно делать и мышкой.

- Пустые строки и строки с `#` (или `//`) — для себя, в игру не идут.
- Регистр и «ё» в командах не важны: `Фон`, `фон` и `ФОН` — одно и то же.
- Стрелка `->` показывает, в какую сцену идёт история.

## Шапка мода

```
@mod_id spasti_katyu            имя папки, латиницей (обязательно)
@mod_name Спасти Катю           название в «Модах»
@author Генри                   автор
@description Пара слов о моде   описание в «Модах» (или @описание)
@вставка day3_olyatalk -> e3_provodit    своя сцена перед меткой игры (см. «Моды внутри оригинала»)
@замена sK2_good -> e4_zhiva             своя сцена вместо метки игры
```

## Сцены и переходы

| Команда | Что делает |
|---|---|
| `: start` | начало сцены `start`. С неё мод начинается |
| `переход night` | дальше идёт сцена `night` |
| `конецигры` | «Конец» и выход в главное меню (`конец` — то же) |
| `оригинал d4_begin` | дальше идёт оригинальная история игры с этой метки |
| `вернуться` | конец вставки: игра продолжается с того места, где мод её прервал |

## Реплики

| Строка | Что выйдет |
|---|---|
| `Мама: Доедай кашу.` | говорит Мама (имя как в игре: Антон, Оля, Полина, Катя, Рома, Бяша…) |
| `мысли: Опять манная.` | мысли Антона, курсивом |
| `Всю ночь ветер скрёбся в окно.` | рассказчик, без имени |
| `Сторож: Кто тут шастает?` | свой персонаж: незнакомое имя мод заводит сам |

## Картинка

| Команда | Пример |
|---|---|
| `фон` | `фон bg kitchen1_1 плавно` — фон игры; `фон чёрный`, `фон белый`; файл игры `фон images/end/runaway.png`; слои через `+` |
| `показать` | `показать Мама Normal m_day 01 norm aside справа плавно` — спрайт игры: кто, эмоция, одежда, лицо; где (`слева`, `справа`, `центр`, `далеко`, `близко`); `рост 80` — размер в процентах |
| `убрать` | `убрать Оля быстро` |
| `окно скрыть` / `окно показать` | спрятать или вернуть окно с текстом |

Переходы в конце строки: `плавно`, `затемнение`, `быстро`, `медленно`, `вспышка`, `сразу`.

Названия спрайтов и фонов писать руками не надо: в карточке «Персонаж» и «Фон» всё выбирается по картинкам.

## Звук

| Команда | Пример |
|---|---|
| `музыка` | `музыка 1_Melancholy(Tiny_Bunny)` · `музыка стоп` |
| `фонзвук` | `фонзвук sounds/fon/001wind.ogg` — по кругу (ветер, улица) · `фонзвук стоп` |
| `звук` | `звук sounds/Door_open.ogg` — один раз |
| `голос` | `голос voice/karina/21 K.ogg` — озвучка следующей реплики |
| `пауза` | `пауза 1.5` — тишина, секунды |

В карточке «Реплика» можно найти записанную в игре фразу по словам. Голос подставится сам.

## История

| Команда | Пример |
|---|---|
| `выбор … конецвыбора` | варианты `- Текст -> сцена`; `выбор подсветка` — пятна на картинке; `выбор время 8` — на время |
| `установить` / `прибавить` / `убавить` | `прибавить смелость 1` |
| `если` | `если смелость >= 2 -> brave` (`>=`, `<=`, `>`, `<`, `=`, `!=`) |
| `достижение` | `достижение Спаситель \| Катя жива` |
| `кнопка` | `кнопка Открыть дверь` — ждёт, пока игрок нажмёт |

Подробно: [Выборы, очки и концовки](choices.md).

## Для тех, кто знает код игры

`код: SK_hard_mode = SK_easy_mode` — одна строка на Python прямо в игре. Ошибка здесь может уронить игру.
