# Моды внутри оригинала

[← Вики](README.md)

Мод не обязан быть отдельной историей. Он может жить внутри самого «Зайчика»: игрок играет как обычно, а в нужный
момент история сворачивает туда, где её раньше не было. Так сделан «Спасти Катю».

## @вставка — своя сцена перед меткой игры

```
@вставка day3_olyatalk -> e3_provodit

: e3_provodit
фон bg road_night затемнение
Впереди, у поворота к гаражам, маячила знакомая шапка с помпоном.
…
вернуться
```

Когда игра доходит до метки `day3_olyatalk`, сначала играет твоя сцена `e3_provodit`. **`вернуться`** в её конце
отдаёт ход игре: экран игры возвращается таким, каким был, и она идёт дальше. `вернуться` нужен в конце **каждой**
ветки вставки.

Вставка может ничего не показывать, если условие не выполнено:

```
: e4_ruka
если доверие >= 2 -> e4_hears
вернуться
```

## @замена — свой поворот сюжета

```
@замена sK2_good -> e4_zhiva
```

Когда игра идёт на метку `sK2_good`, вместо неё играет твоя сцена. Дальше решаешь ты: `конецигры` (своя концовка)
или `оригинал какая_то_метка` (вернуться в игру в другом месте).

## Где брать метки

Метки — имена кусков сценария внутри скриптов игры, латиницей: `day3_olyatalk`, `d4_begin`, `sK2_good`. Их видно,
если распаковать скрипты игры декомпилятором [unrpyc](https://github.com/CensoredUsername/unrpyc). Самые полезные
уже стоят в «Спасти Катю», смотри его шапку.

## Как устроен «Спасти Катю»

В игре Катя гибнет в гараже при любом раскладе. В моде её можно спасти, если раньше быть к ней человеком:

| Эпизод | Метка игры | Что добавляет мод |
|---|---|---|
| 2 | `bunny2_meet_pol` | Катя одна у окна. Подойти, пройти мимо или буркнуть «ябеда» — `доверие` |
| 3 | `day3_draw_fox` / `day3_draw_notfox` | рисунок Кати: красиво или с рожками — `доверие` |
| 3 | `day3_olyatalk` | вечер у гаражей: выбор на время, проводить, суефа «на портфель», достижение «Рыцарь» |
| 4 | `sK1_good` | в мясорубке: если `доверие >= 2`, Катя слышит Антона и борьба становится легче (`код:`) |
| 4 | `sK2_good` → **замена** | Катя живая: снег, милиция, больница, полароид, достижение «Спаситель», своя концовка |

Мод лежит в `projects\spasti_katyu\story.txt`, открывай и разбирай.

## Осторожно с кодом

`код:` меняет переменные самой игры (как `SK_hard_mode = SK_easy_mode` в «Спасти Катю»). Это мощно, но ошибка в
строке может уронить игру. Проверяй через «▶ Играть».
