# Камера, движения и эффекты

[← Вики](README.md)

«Зайчик» оживляет неподвижные картинки камерой и мелкими движениями. GenryTB делает то же самое, и превью
проигрывает всё вживую: жми «▶ просмотр».

## Камера

```
камера наезд | 960 330
камера шаги
камера стоп
```

Двигается весь кадр: фон и все, кто на нём. Камера держится, пока не скажешь `камера стоп` или не сменишь фон.

| Слово | Что происходит |
|---|---|
| `наезд` | камера медленно приближается к точке |
| `отъезд` | камера медленно отъезжает |
| `крупно` | резко и близко: лицо, рука, записка |
| `рывок` | кадр дёргается вперёд и назад, испуг |
| `влево`, `вправо` | камера плывёт в сторону |
| `шаги` | кадр покачивается: герой идёт |
| `бег` | кадр трясётся: герой бежит |
| `дыхание` | кадр еле заметно дышит |
| `качка` | кадр плавно качает: голова кружится |
| `дрожь` | кадр мелко дрожит: страх, холод |
| `сердце` | кадр бьётся, как сердце |
| `мышь` | кадр плывёт за мышкой, как меню игры |

Для `наезд`, `отъезд`, `крупно`, `рывок` и `сердце` можно указать точку: `| x y` на экране 1920×1080. В карточке её
таскают по превью кружком с прицелом.

## Движения персонажа

```
движение Катя вздрог
движение Алиса смеётся
движение Алиса стоп
```

| Один раз | Всё время, пока не скажешь `стоп` |
|---|---|
| `вздрог` — вздрагивает, как в игре | `смеётся` — трясётся от смеха |
| `радуется` — приседает от радости | `дрожит` — мелко дрожит |
| `прыжок` — подпрыгивает | `идёт` — покачивается на ходу |
| `кивок` — кивает | `дышит` — еле заметно дышит |
| `мотает` — «нет», влево-вправо | `плачет` — плечи вздрагивают |
| `отпрянул` — резко назад и обратно | |

## Погода

```
погода снег
погода метель
погода нет
```

Снег из самой игры поверх сцены. Он идёт до нового фона: новый фон даёт чистый кадр.

## Плёнка

```
плёнка vhs
плёнка нет
```

| Слово | Что происходит |
|---|---|
| `vhs` | девяностые: затёртая кассета, полосы, цветные края, ползущая помеха |
| `помехи` | телевизионный «снег» |
| `воспоминание` | старое кино: рамка и царапины |
| `телевизор` | сцена идёт на экране старого телевизора из самой игры |
| `глазок` | вид через дверной глазок |
| `нет` | обычная картинка |

Плёнка держится, пока не поставишь `нет`. Подходит для воспоминаний, снов и записи с камеры.

## Мелочи

| Команда | Что делает |
|---|---|
| `тряска` | экран вздрагивает |
| `вспышка` | белая вспышка |
| `надпись День пятый \| 3` | крупные буквы посреди экрана, 3 секунды |
| `пауза 1.5` | тишина перед важной репликой |
| `показать … рост 120` | персонаж крупнее или мельче (проценты) |
