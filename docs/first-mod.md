## 1. Новый мод

Запусти GenryTB. Главное меню выглядит как меню самого «Зайчика». Нажми **«Новый мод»**, впиши название, имя
автора и пару слов о чём он (это описание видно в игре, в «Модах»), потом **«Создать»**.

## 2. Карточки

Редактор устроен так:

- **слева** список сцен мода (первая всегда `start`);
- **посередине** карточки текущей сцены;
- **справа** превью: кадр игры ровно таким, каким его покажет игра.

Внизу кнопки по разделам: «Реплика», «Фон», «Персонаж», «Выбор», «Суефа», «Камера»… Каждая добавляет карточку
после выбранной. Карточки перетаскиваются за точки слева, удаляются крестиком.

Попробуй так:

1. **Фон** → выбери кухню.
2. **Персонаж** → Мама, любое лицо.
3. **Реплика** → «Мама: Доедай кашу». Нажми **Enter**: появится следующая реплика тем же голосом.
4. **Выбор** → два варианта, у каждого стрелка «куда». Там же можно сразу создать новую сцену.

Превью показывает каждый кадр. **«▶ просмотр»** (пробел) проигрывает сцену прямо в редакторе: с камерой, снегом и
движениями.

## 3. Текстом, если так быстрее

Вкладка **«Текст»** — тот же мод обычным текстом. Это удобно, если пишешь много реплик подряд:

```
: start
фон bg kitchen1_1 плавно
показать Мама Normal m_day 01 norm aside плавно
Мама: Доедай кашу.
мысли: Опять манная.
выбор
- Доесть -> eat
- Сбежать в школу -> run
конецвыбора
```

Карточки и текст — одно и то же. Правишь в одном месте, меняется в другом. Все команды есть в
[Шпаргалке](commands.md).

## 4. В игру

- **«▶ Играть»** (F5): мод собирается и игра запускается с его первой сцены.
- **«▶ Эта сцена»** (F6): запуск прямо с той сцены, которую правишь.
- **«В игру»**: мод просто кладётся в игру. В главном меню «Зайчика» появляется **«Моды»**, а в ней твой мод.

Ошибки видны сразу. Строка, которую мод не понимает, становится красной карточкой с подсказкой, как надо. Сверху
счётчик «ошибок: N — показать». Пока ошибки есть, мод в игру не пойдёт.

## 5. Где лежит

Каждый мод — папка `projects\<id>\` с одним файлом `story.txt`. Его можно открыть блокнотом, переслать другу или
выложить. В игре мод лежит в `game\mods\<id>\`.
